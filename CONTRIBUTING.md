# Colaborar con PixelCrochet

1. Abre un issue describiendo la mejora o el problema y los pasos para reproducirlo.
2. Crea una rama desde `main` y una pull request con un resumen claro.
3. Ejecuta `npm run build` y, si tocaste el motor Python, `npm test`.
4. Comprueba los anchos 375 px y 1024 px, los dos idiomas y los dos temas.
5. No cambies `public/algorithms/original_cell.py` ni el notebook sin validación científica y discusión previa.

La interfaz debe seguir siendo accesible, táctil, bilingüe y usable sin conexión.
